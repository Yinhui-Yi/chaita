# ChaitaAssistant（拆塔辅助）

盖在魔塔游戏旁边的悬浮层。**只给信息，不给结论** —— 该不该打、先打谁、走哪条路，是你的乐趣，它不插手。

三个功能：

| 功能 | 怎么用 | 它给你什么 |
|---|---|---|
| **读怪物手册** | 游戏里翻到怪物手册页，点「读取」 | 每只怪的生命/攻击/防御/经验 + 技能 + 缩略图 |
| **读地图** | 进到能看见地图的画面，点「读取」 | 层号、这层有哪些怪（各几只）、这层有什么资源（血瓶/宝石/钥匙） |
| **对话** | 底部输入框说一句话，回车发出去。不用先点「读取」 | 能聊天、能问事（"这层有什么"），也能顺手纠正读错的数字（"生命是1200"）；说过的话都留在「对话」那一段里，下一句记得上一句 |

**不做的事：** 不算伤害、不判断能不能打、不识别格子、不规划路线。也不算"临界值/减伤"这类要动脑的东西。

## 支持的两座塔

| 塔 | 引擎 | 窗口进程 |
|---|---|---|
| 教程塔 | RMXP（RGSS Player） | `game.exe` |

两塔界面结构不同，各自有一份描述（`chaita/game/towers.py`）。

## 用

1. 打开游戏，进到要看的那一页（地图 / 怪物手册）
2. 双击 `拆塔辅助.lnk`（不闪黑框：`.lnk` → `启动.vbs` → `run.py`）
3. **把游戏窗口点到前台**
4. 点悬浮层顶栏的「读取」
5. 等结果落进面板

| 操作 | 效果 |
|---|---|
| 顶栏「读取」 | 读当前画面（地图 → 怪+资源+状态；手册 → 这一页的怪） |
| 地图每层行尾「↻」 | 只用那层的截图重读"有哪些怪、各几只"（不碰状态和资源） |
| 状态区「↻」 | 只重读左边状态面板（血/攻/防/钥匙），比重读整张地图快 |
| 行首方框 | 勾「打过了 / 拿过了」 |
| 「＋ 加怪」/「＋ 加资源」 | 手动加一行（AI 读错时自己补） |
| 每层「备忘」 | 给这层记一句话（会跟着上次记录保存） |
| 点顶栏**任何地方** / 拖顶栏 / 拖边缘 | 折叠展开 / 移动 / 缩放 |
| 右上 `×` 或 `Esc` | 关闭（只有一个实例：再点一次启动器不会叠出第二个） |

**只读前台的游戏窗口。** 前台不是游戏、或者同时开着两个游戏窗口时会明确提示，不猜。

## 时间预期（2026-10-26 实测，关掉思考之后）

| 动作 | 耗时 | 说明 |
|---|---|---|
| 一次模型往返 | **1.7 ~ 2.3 秒** | 关思考后的基线 |
| 对话 | **3.0 ~ 3.3 秒** | 一次往返 |
| 读怪物手册（一页 5 只怪） | **21 ~ 110 秒** | 取决于模型这一轮调几次 `look`/`sprite` |
| 读地图（层号+怪+资源） | **32 ~ 80 秒** | 同上 |

`look`/`sprite` 是给模型"放大看清"和"抠图标"的工具，每调一次就是一次往返。
它有硬上限（整页 look 6 次、每只怪 sprite 3 次），防止模型钻牛角尖跑不完。

## 图标

- 默认：模型在手册页上框出那一格，代码裁下来当图标（**带手册底纹**，因为没抠图）。
- 想干净：把 `u2net.onnx` 放进 `C:\Users\87790\.u2net\`（rembg 的模型），
  代码不用改，`sprite` 会自动走抠图；没有这个文件就退回纯裁剪 —— **没有模型时
  不会去下载**，所以不会把「读怪物」卡成没反应。
- 素材库（`assets/monster_icons/`）只给「加怪」下拉选图用；按名字去顶替手册读到的
  图标意义不大（实测 5 只怪只中 1 只，且 26×25 比模型裁的 157×146 小很多）。

## 已知限制

- 浏览器多个标签时，抓的是**窗口当前显示的那个**，无法指定标签页
- 只支持点按钮读一次，没有自动持续读取
- 读地图给的怪名会受面板里已有名字影响（换来的是两次读同一张图结果一致）
- 画面校验是启发式的（按亮度判断），暗色主题网页可能骗过它
- 地图上怪的小图标只有十几像素，名字本质上是模型在猜；把「读怪物手册」先读一遍，
  名字会准很多（读地图会拿手册里的名字当候选）

## 怎么工作

```
点「读取」
   ↓  先抓图（PrintWindow，被遮挡也能抓）—— 拿到"点下去那一刻"的画面
判画面：这是地图 还是 怪物手册？
   ↓
地图  → agent.map.read   一个会话里问三句：层号 / 这层有哪些怪 / 有什么资源
手册  → agent.monster.read 一个会话里 look 放大 + sprite 抠图标
对话  → agent.chat.reply 一次往返：聊天 / 问事 / 顺手改字段，最近 8 轮一起带上
   ↓
落进面板（并可选地把这次的地图存进"这一层"的记录）
```

**一张图只上传一次**：同一屏上的几个问题在同一个会话里追问，后面只发文字。

细节和"为什么这么选"见 [`docs/SOFTWARE_DESIGN.md`](docs/SOFTWARE_DESIGN.md)，
逐轮改造见 [`docs/REDESIGN_NOTES.md`](docs/REDESIGN_NOTES.md)。
