# 路线链（长按拖线 → 交互路线 → 沿链算掉血）

> 状态（2026-10-28）：**做完**。"点图片放大"已经删干净（`previewUrl` /
> `views/preview/Preview.qml` / 三个点击入口全部移除）；长按玩家 → 拖红线 →
> 松手生成路线链；链上照伤害计算摆**箭头 + 缩略图**（只摆怪/宝石/血瓶），
> 链尾「计算」沿链跑 `chaita/game/battle.py`，掉血写格后、总掉血/剩血在底栏。
> 刷新地图时会顺带记下**每个格子有什么**（怪 / 宝石 / 血瓶），拖完路线直接预填；
> 路线还能「复制」→ 粘贴进伤害计算界面。

> 目标（用户原话）：**在小界面长按玩家启动路线提取**，把之前的"点图片放大"删掉；
> 点玩家有选中格效果（起点红点），鼠标移到下一格也要选中，同时画红线表示路线；
> **必须支持走回头路**；松手后自动生成一条"交互路线"（类似伤害计算界面），
> 也要能拿它做伤害计算。
>
> 后来补的（用户）：**"一般魔塔 13×13"**（行列写死 13，不读 AI —— 模型数出 14/15 反而带偏）、
> **"仿照伤害计算界面，用箭头和缩略图"**、**"非怪和宝石血瓶不需要显示"**、

## 1. 入口与手势

| 现在 | 改成 |
|---|---|
| 地图缩略图 / 「这一层」小窗整图 / 清单缩略图 点一下 = 放大看图 | **已经删掉**（`views/preview/Preview.qml` 一并删） |
| 「这一层」小窗里的整图只能看 | **长按 500ms 玩家所在格 → 进入路线提取**（`route_layer/RouteLayer.qml`） |

- 为什么选「这一层」小窗的整图：缩略图只有 58px 高，一格不到 3px，拖不准；
  小窗里那张图能拉到 700px 高，一格的像素够点。
- 长按判定：`MouseArea` + `Timer(500ms)`，按下开始计时，移动超过 6px 或松手就取消
  （否则会和"拖窗口"抢手势 —— 小窗四周那圈才是拖窗口，图上是拖路线）。
- 选中的样子（用户："你画的格子完全不像选中状态"）：**红底 + 红框**，
  起点更重、还有一个白圈红点；格子中心之间连 2px 红线（拐点圆角）。

## 2. 格子从哪来

- **尺寸 = 图实际画出来的那块宽 ÷ 13**。魔塔一层就是 13×13（用户拍板，写死
  `win.routeCols = 13`，不再让 AI 数行列 —— 模型数出 14/15 反而把红线带偏）。
- QML 的 `Image` 用 `PreserveAspectFit`，所以路线层贴在 `paintedWidth/paintedHeight`
  那块矩形上（`FloorSheetWindow.qml` 的 `shotDrawn`），不是贴截图外框 ——
  贴外框整条线会偏（用户："格子会偏"）。
- **每个格子里有什么**由 AI 在刷新地图时读（`agent/map/read.py` 的 `GRID_QUESTION`）：
  只记怪/宝石/血瓶，坐标从 1 数、**存下来换成 0 开始**、框在 1~13 内。
- 只有"哪一格是哪一格"是几何换算（原点 + 边长），代码不做任何像素识别。

## 3. 拖动与回头路

```
起点：红点 + 红底格
移动：鼠标进入相邻格（四向）→ 该格加红底 + 从上一格画红线
回头：退到**走过的任何一格**（包括紧邻的上一格）= 记成"回头路"，链上如实追加
     （用户 2026-10-29："前进一格再后退一格也要记成来回"，撤销逻辑已删）
松手：结束，生成并**立刻摆出**这条路线链
```

- 手势和选中状态都由路线层自己管（`RouteLayer.cells`，按走过的顺序、**允许重复**）；
  松手时交给 `controller.saveRoute(floor, cells)` 存进那一层的 `routes`，随会话保存。
- 画线：每两格之间一条 2px 红线（`#C23B2E`，和宝石"攻击"同色），拐点圆角；
  起点是白圈红点。

## 4. 路线链（`views/route_editor/`）

- 松手就开一扇链窗口（和伤害计算同一个形状：无边框 + 置顶 + Qt.Tool，**四边四角都能拉大小**），链的**长相
  完全照伤害计算**：`勇者 → 缩略图 → 缩略图 …`，格与格之间是同一个箭头控件
  （`views/shared/ChainArrow.qml`，伤害计算也用它），缩略图 14px，掉血写在格后
  （用户："仿照伤害计算界面，用箭头和缩略图"）。
- **只摆怪 / 宝石 / 血瓶**（`routeShown` / `routeChainRows`）：空的走过格、门、
  钥匙、武器、防具都不出现在链上 —— 它们和"这条路上掉多少血"无关，摆出来只会吵
  （用户："非怪和宝石血瓶不需要显示"）。没图标的格子写名字的头一个字。
- **预填**：刷新地图时记下的"这一格有什么"（`entry["grid"]["cells"]`）在
  `saveRoute` 里按行列对进去 —— 怪连手册里的数值/技能一起带上，宝石/血瓶连
  图标/效果一起带上，不用一格一格点。
- **点缩略图 = 改参数**（用户："点缩略图出来的是什么垃圾？怎么和伤害计算不一样"）：
  和伤害计算**同一张卡片**（`route_editor/edit_card/EditCard.qml`）：数量、血量/攻击/防御、
  资源效果、技能参数都一样，底部也一样 ——「删掉这步」（清掉这一格的内容）+「完成」。
- **点箭头 = 换这一格是什么**（怪 / 资源 / 门 / 清空）：和伤害计算"点箭头插入"同一个
  分工（`ChainArrow`），下拉菜单见 `route_editor/pick_menu/`。
- **计算**：链尾「计算」（和伤害计算一样，算完就藏），把格子按顺序喂给
  `battle.run_plan`（和伤害计算同一个公式，不另写一份）；掉血写在**格后** `（−930）`，
  总掉血 / 剩血钉在链右边（人倒了标红）。门/空格按 `empty` 占位，保证结果行和格子对齐。
- **复制 / 粘贴**（用户："路线要能复制，可以粘贴到伤害计算界面"；又骂过
  "谁复制东西这么复制的"——所以是真系统剪贴板，不是内存变量）：链窗口抬头
  「复制」（或 Ctrl+C）把链上的怪/宝石/血瓶写成 JSON 进**系统剪贴板**
  （`controller.clipboardCopy`）；伤害计算窗口顶栏「粘贴」（或 Ctrl+V）从
  **系统剪贴板**读回（`controller.clipboardText` + `routeParseClipboard`），
  只认那种 JSON，别的文本不起行。
- **路线对比**（用户："入口就在伤害计算的右边；把算好的路线复制或拖进来，
  显示每只怪的掉血，多条路线时对比每只怪在不同路线的掉血"）：导航条 ⚔ 右边
  的 ⇄ 打开 `views/route_compare/CompareWindow.qml`。一条路线一列、一行一只怪
  （按「怪名 + 第几只」对齐），底下是各路线总掉血 / 剩血。导入两条路：
  「粘贴」读同一种 JSON；链窗口抬头的「拖」把手（`routeDragOut`）把同一份
  JSON 塞进 `Drag.mimeData` 的 `application/x-route-json`，对比窗的 DropArea 收。
- 对比表的**第一列不写怪名**（用户："不要写怪物名字！！！用缩略图和坐标！！"）：
  缩略图 + 「第几行第几列」（从 1 数，和「这一层」的「位置 3,4」同一个规矩）。
  名字只留在数据里做对齐（同一条线上同名的第几只）和没图时的占位首字。
  缩略图来源和路线链一样：手册裁的图（`icon`）→ 素材库按名字找。
- 坐标跟着「复制」的 JSON 一起走：`routeStepsFor` 给每一步怪带上
  `floor/row/col`，`routeStepsJson` 再把同层路线缺的 `floor` 补成路线自己的层。
- **点一行 = 去地图上圈这一格**（用户："最好点击后会在地图内高亮"）：
  `compareHighlight` 把 `mapHiFloor/mapHiRow/mapHiCol` 写进主窗口并开那一层的小窗
  （已开着就提到前面）；小窗里 `floorCellHighlight` 在截图对应的格子上画
  淡黄底 + 深琥珀框 + 白边光晕。关对比窗（或「清空」）就把它清掉。
  老路线没有坐标（点之前存下来的 JSON）点了什么都不做。
- 底栏那**一大块黄底**（纸色 `paperLo` 的合计条）已经从伤害计算和路线图两个窗口删掉，
  不写"点这算那"的提示 —— 结果直接写在各行/链的右边。
- 链上的怪用 `battleMonsters()` 那份（生命/攻击/防御/技能参数），资源用
  `routeItems()`（`battleItems()` 里只留宝石和血瓶）—— 同一个数据源。

## 4.6 路线备注（用户："把路线的 xx格 删掉改成备注"）

- 每条路线带一个 **备注**（`entries["routes"][i]["memo"]`，`controller.saveRouteMemo`），
  「这一层」清单的路线行从"路线 N：几格"改成"路线 N + 一个备注框"，可改可加字。
- **默认值** = 走完这条路线之后的**血 / 攻 / 防 / 魔防**（`routeStatsMemo`：拿预填好的格子跑
  `battle.run_plan`，再用 `result.stats` 拼成"血 X · 攻 Y · 防 Z · 魔防 W"）。
- 走过一次就"清空"：怪打死 / 资源捡走，回头再走同一格不再算（`routeStepsFor` 的去重）。

## 4.5 格子编辑模式（用户："读出来一大半都是错的" → 手动纠正坐标）

AI 读的 `grid`（每个格子里有什么）读错大半，所以「这一层」小窗加了**编辑模式**：

- 地图截图右上角「编辑」按钮开关；开着时地图上盖 **13×13 坐标线**
  （`floor_sheet/grid_layer/GridLayer.qml`），鼠标悬停哪格高亮哪格。
- **长按 500ms 抓起一格**（浮起一个小牌子"格 x,y"）→ 拖到下方**怪 / 资源词条**上松手，
  就把这个坐标记给那个词条（`controller.assignGridCell` → 写进 `entry["grid"]["cells"]`，
  一格只留一样，旧记录被顶掉）。
- **短点**一格（有内容）= 清掉这一格；词条下面在编辑模式里**标出它出现的每个位置**
  （`位置 3,4 · 6,2`，1 开始）。
- 编辑是即时落库（`mapHistoryChanged`），退出编辑就带着改好的 json；拖新路线时
  预填读的就是这份改好的 `grid`。
