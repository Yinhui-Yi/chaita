# 拆塔辅助 · 界面设计

> 现状说明，不是提案。实现在 `chaita/ui/qml/MainWindow.qml`（全部界面）、
> `chaita/ui/controller/`（数据），逻辑在 `chaita/game/`。
> 成品图：`logs/design/*.png`，实拍在 `logs/_scenarios/*.png`。
> 每条规则后面括号里是用户的**原话** —— 都是为了记住"为什么这样"，别再改回去。

## 0. 一条被推翻的产品判断

旧版把「本层」当主角（抬头是层号，下面是这一层的清单，怪物/技能降成资料）。
用户连否几次，说清了三件事：

1. **AI 是聊天对象，不是读图器** —— 对话必须在界面上、要能一直用；
2. **主角是整座塔**，不是某一层 —— 要看每层地图、有哪些怪、哪些资源、哪些技能；
3. **汇总一直看得见** —— 想看"带某技能的怪还剩几只"不该先搜索。

所以这一版的主语是**塔**；"一层"的东西只出现在地图块和小窗里。

## 1. 主界面

一张 340 宽的卡片，从上到下：导航条 → 抬头 → 状态 → 内容 → 对话，
靠留白和字号分节，**没有卡片套卡片**：

```
┌ 🧙 拆塔辅助                            ↻   ✕ ┐  导航条：图标 + 软件名 + 刷新状态 + 关闭
│ 坐牢成仙 地下30                              │  抬头：塔名（读不到就整行不占位）
│ ♥1200  ⚔60  🛡20  🛡5                       │  状态第一行：生命/攻击/防御/魔防
│ 🪙9800  🔑4  🔑2  🔑1  🔑0                  │  状态第二行：金币 + 四色钥匙
│ 上次的记录：10-26 15:20 · 6 层 / 14 只怪 恢复 忽略 │  有存档才出现
│ ▾ 地图                            19:13 读取 [读取] │  标题可点＝折叠；读取只读地图
│ [地图块] [地图块] [地图块] …                       │  一行三个
│ ▾ 怪物                      4 种 · 共 13 只 · 剩 13 [读取] │  汇总常驻；读取只读手册
│ [图] 监狱守卫  先攻·纳魔为攻            ×6   剩 6   │  一行一只
│      生命 21000万 · 攻 6100万 · 防 3500万            │
│ 技能                        3 种 · 涉及 12 只        │
│ 先攻                          12 只 · 剩 12          │
│ 读取记录                            读着 2 条 · 共 4 条 │  有任务才出现
│ ● 地图 读取中…                        12s  取消    │
│ ┌ 对话 ───────────────────────────── 14:32 ┐        │  完整历史（最多 40 条）
│ └ [                      ]                 [↑] ┘     │  空输入条，没有任何默认提示
└──────────────────────────────────────────────┘
```

- **导航条**（22 高）：勇者图标 16 + 软件名 11/700 + **刷新状态 ↻** + 关闭 ✕。
  ↻ 只刷人物面板（`updateStatus()`，刷新中变 `…`），和关闭放一起、**不单占一行**
  （用户："刷新不要单独一行"）。游戏数值不往这里塞（用户："血量钥匙道具显示的
  位置不合理"）。
- **抬头**（24 高）：只有塔名（16/700，太长省略号）。拖动和"点空白收起"都在这行。
- **状态区**（30 高，有值才占位）：生命/攻击/防御/魔防一行，金币+四色钥匙一行
  （用户："血攻防魔防一行，钥匙一行"）；`statusVisible` 决定占不占高，收起时也留着。
- **上次的记录**（20 高，有存档才有）：`恢复` / `忽略` → `restoreSession()` /
  `discardSession()`。不自动恢复 —— 旧血量会误导人。
- **地图**：一层一块（100×92，缩略图 58 + 层号 + "N 怪 · M 只"），一行三个
  （`tileW = (bodyW-16)/3`），整页一起滚，不做嵌套滚动。缩略图 `PreserveAspectFit`
  （整张地图都看得见，只缩不放）；块右上角 **↻** 重数这层的怪**和资源**
  （`refreshFloorCounts` → `read_floor_map`，数的时候图标变 `…`）。
  **点一块进这一层的小窗**（§1.5）。这一栏的「读取」= `readOnly("map")`。
- **怪物**：一行一只（36 高）：缩略图 24、名字 13/700、技能 9/灰、`×N` 10、
  `剩 N` 12/琥珀/700、数值行 9/灰（生命·攻·防）、行尾 `✕` 删除。
  **不带层号**（用户："怪物不要层数，要生命攻击防御"）—— 同名的只数已经跨层加过。
  这一栏的「读取」= `readOnly("monsters")`。
  - **按住一行上下拖 = 改顺序**（用户："要能通过拖动修改顺序"）：顺序就是
    `_monsters` 的顺序；落点由 Python 每 40ms 读系统光标算（QML 抓取式拖拽指针
    一离开行就被 canceled）。拖的那行淡到 45%、目标行顶上一条琥珀线；
    走 6px 才算拖（不然手抖会把"点开编辑"变成排序），拖动期间列表不跟着滚。
    读手册、改名都不会打乱它。
  - **行尾 ✕ = 删掉这只**：`removeMonsterByName(name)` 同时删手册记录和各层地图
    记录（只删手册的话，地图上用到它的层还会把这行顶出来）。
- **地图 / 怪物两栏能折起来**（用户："地图和怪物怎么不能折叠？"）：栏目标题本身是
  按钮（带 `▾`/`▸`，悬停变琥珀），点一下收起、再点展开。收起的是整块内容
  （`visible: false`，`Column` 不给不可见的留位置），窗口高度按
  `flick.contentHeight` 自己缩（样例 657 → 466）。「读取」按钮留在标题右边，
  收起也能读；地图收起后标题补「地图 N 层」。折叠状态只活这次会话，重启回展开。
- **技能**：一行一个（28 高），名字 12/700 + 右侧"`N 只 · 剩 M`"10/琥珀/700。
  **不列带这个技能的是哪些怪**（用户："技能部分不需要带怪物"）。
- **对话**：底部一张卡：**完整历史**（用户："我需要完整的历史，这才符合直觉"；
  `chatLog` 最多 40 条，`你/AI` + 正文 9 + 时间 8）+ 输入条 + 发送 ↑。
  正文**按宽度折行、不 elide**（用户："每一行的内容超出行的部分会被截断"），
  卡片高度 `8 + 实测行高 + 5 + 26 + 7`（最少 46），超 180 就在卡里滚并自动停在
  最新一句；没有对话时只剩输入条。**没有任何默认提示文案**（用户："默认提示都删掉，
  真low"）。读取按钮不在这里（用户点名挪到地图/怪物那一侧）。

## 1.5 「这一层」——一扇独立的窗口

点地图块打开；**可以多开、可以拖、可以拉大**，而且是**真窗口**（无边框 + 置顶 +
`Qt.Tool`），所以**能拖到软件外面**（用户："地图的小窗怎么不能移动 / 怎么不能多开 /
怎么不能放大 / 为什么不能移动到软件之外"）。

> 以前它只是主窗口里的 `Rectangle`：Qt Quick 的元素一律被自己的窗口裁掉，所以只能
> "钳在窗口里"。现在每开一层就是一扇 `Component { Window { … } }` 实例
> （`floorSheetWindow`），拖抬头改的是**窗口坐标**（`mapToGlobal` 算，窗口跟手不漂），
> 边界是**屏幕**（底部留 56 给任务栏），位置/大小记在 `floorPositions` /
> `floorSizes`（屏幕坐标）。主窗口 `onClosing` 时 `closeAllSheets()`（`Qt.Tool`
> 不会跟着主窗口走，不收掉进程会留着）。

```
┌ 地下30                              ＋ ✕ ┐  ← 拖抬头挪窗口；＋ 再开一层
│ [整张截图 · 点开看大图]                    │
│ 怪物                            [＋ 加怪] │  ← 点开是挂在按钮下的下拉
│ ○ [图] 血蚊        [3]              ✕    │  ← 行高 24（20 的图 + 上下各 2）
│ 资源                          [＋ 加资源] │  ← 同上，不是整页挑选页
│ ○ [图] 红血瓶  体力 +150  [3]        ✕    │
│ 备忘 [                              ]    │
│ [刷新本层] [删除本层]          [完成] ◢   │  ← 右下角 ◢ = 拉大（四边四角都能拉）
└───────────────────────────────────────────┘
```

- 打开的是**一组**（`floorWindows` 名字列表 + `floorSheets` 名字→窗口，
  `syncFloorSheets()` 补/收）。默认贴着地图块下沿往下开；没拉过时高度按内容长、
  封顶约 390（截图区最高 240），清单在窗内滚。
- **拖动**：拖窗口本身；**每一步都把位置钳在屏幕里**（越界的那截不攒着，否则往回拖
  要先"还债"，用户："拖动时一直在抖动"）。
- **拉大小**：四条边 + 四个角都能拉（用户："怎么只有右下角能拉伸窗口"）——
  `SheetGrip` 一个组件摆 8 处（`floorGrip` 是右下角那个，带三道斜线标记；
  `floorGripL/R/T/B` 是四条边，`floorGripTL/TR/BL` 是另外三个角），
  光标按方位给 `SizeHor/SizeVer/SizeFDiag/SizeBDiagCursor`。
  位移一律用**屏幕坐标**算（窗口自己在动，用窗口内坐标会越拖越小），每帧把新尺寸
  记进 `floorSizes`（这扇窗的宽高是绑定出来的，不记就会被顶回去）。
  最小 230×180、最大不超屏幕；拉大之后清单吃掉多出来的高度（`listMax`）。
  关掉再开还是这个大小。
- **截图区跟着卡片变大**（用户："放大地图的小窗的时候地图不会一起变大"）：宽度铺满，
  高度按截图比例（不裁剪）；连宽一起拉才变大，只拉高时受比例限制。
- **`＋ 加怪` / `＋ 加资源` 是挂在按钮下面的下拉菜单**（用户："地图下的加怪和加资源
  怎么不是下拉菜单"）：`pickMenuLayer`（整层透明，点外面收起）+ `pickCard`
  （208 宽、列表最多 220 高，窗内滚动）。菜单画在**这一扇窗自己**里，位置由
  `openPickMenu(mode, floorText, button, replaceIndex, host)` → `placePickMenu()`
  按按钮在本窗坐标算：正对按钮下沿 4px，右边放不下贴右侧，下面放不下翻到按钮上面，
  列表高度按小窗高度收；标题写「加怪到 地下30」/「加资源到 地下30」。
  点行才落地（`addFloorMonsterFull` / `addItemFull`）；点空白、`Esc`、切窗都收起。
- 关：✕ 关那扇；`Esc` 关焦点所在的那扇。**不盖遮罩**，下面的地图块一直点得到。
- 看大图：点截图铺在主窗口里（`previewShot`），看图期间先把小窗藏起来
  （`hideSheetsForPreview()`），关掉再放回。
- 行内改名字/数量/效果（回车或失焦即存）；○/● 标"打过了"；`刷新本层` 走
  `refreshFloorCounts`（怪 + 资源一起重数）；`删除本层` 两步确认。
- **抬头只写层名**：原来那行 `N 怪 · M 资源 · 剩 K` 删了（用户："标题里的怪物数量
  资源数量，剩xxx都删了，毫无意义"），`sheetMeta()` / `sheetLeft()` 一起删。
- **资源行**（用户四条反馈：只有数值和数量能改 / 资源不按习惯排序 / 小窗矮时菜单显示
  不全 / 种类不全）：
  - **行里不写名字，用缩略图代替**（用户："不要写什么 X宝石 / X钥匙，用缩略图代替"）：
    缩略图 24px，没图就画占位框 + 首字，保证每行都有图位；
    **点图标**弹"换成什么"（`setItemKind`），选中把名字/图标/默认效果一起换
    —— 这也是现在唯一改种类/名字的入口。
  - **图标和效果一律以道具表为准**（用户："地图我点刷新，怎么读进来的资源还是没有
    图标？"）：刷新/读图（`_apply_scan` / `_attach_items`）只拿到名字和数量，图得按
    "名字 → 道具表"查（红血瓶=potion_red）再补。规则只有一份实现
    —— `Controller._fill_item_display()`，**主界面地图块**（`_get_map_history`）和
    **「这一层」清单**（`sortedSheetItems`）都走它，落库的时候也用它把记录填完整。
    以前只有主界面补，清单那张空白就一直露着。查不到图的（塔里自己加的道具）不硬凑，
    还是占位框 + 首字。
  - **效果拆两截、写在图后面**：属性（体力/攻击力/防御力…）由道具表写死、只读，
    数值是输入框（`iteminfo.split_effect` / `join_effect`，存回去还是"属性 +N"）——
    用户："后面要写效果比如攻击力+2，攻击力几个字不能改只有 2 能改"；
    手改过的行打 `effect_manual`，显示层不再拿表盖回去。
  - **排序**（owner 2026-10-27 定）：**宝石（红蓝绿黄）→ 武器 → 防具 → 血瓶 → 钥匙 →
    其他**；宝石里按 红/蓝/绿/黄，其它类按颜色（黄/蓝/红/绿/铁/魔）再按数值
    （`iteminfo.sort_key`）。界面用
    `controller.sortedSheetItems()`（每行带 `_src` 真实下标，改/删/勾按 `_src` 走）。
  - **"有哪些资源"只有一处来源**（owner 2026-10-28："这地图下得加资源都是什么乱七八糟
    的，我应该明确指定过有哪些吧"）：**`assets/items/map.json`** —— owner 自己指定的
    "资源名 → 图标"，按图标去重、血瓶合并成一条，`iteminfo.choices()` 就返回这 7 条
    （红宝石/蓝宝石/绿宝石/黄宝石/铁盾/血瓶/黄钥匙）。两座塔的
    `project/items.js` 导进来的 `assets/item_catalog.json`（99 条）**只用来查图标和
    效果**（`iteminfo.icon_for` / `effect_for`），不再往下拉里塞 —— 以前整表并进去，
    下拉 76 条里一大半是"宝石锄头 / 深红(Z3) / 圣锤"这种**别的塔**的道具。
    要加新资源就在 map.json 里加一条（界面里换图标时也会自动写进去）。
  - **小窗很矮时菜单也完整**：`placePickMenu()` 取上下空间大的一边、列表按那边收、
    整块钳回窗里。`Item.window` 在动态创建的窗口里读出来是 `null`（实测），所以宿主
    窗口由调用方递进来（`openPickMenu(..., host)` → `win.pickHost`）。
- **刷新合并：同一种东西只留一行**（用户："我二次刷新时，地图的怪和资源会累计"）
  —— 同一张图读两次，第一次 `红药水 4`、第二次 `红血瓶 4`，按名字合并就会一瓶变两行、
  主列表 ×N 翻倍。现在：资源按**图标身份**归一（`iteminfo.key_for`），怪按**手册写法**
  归一（`monster_names.align`），旧重复行收掉（数量取大的），数量是**替换**不是累加，
  这次没读到的旧条目照旧不删。

## 1.6 怪物编辑 + 素材库

点怪物行打开（`monEditDialog`，z 60，居中卡片，高度跟内容走）。

```
┌ [图] [ 监狱守卫                ]            ✕ ┐   ← 点头像换图；名字在抬头里改
│ 生命 [21000万] 攻击 [6100万] 防御 [3500万]     │   ← 生命/攻击/防御 一行
│ 金币 [       ] 经验 [500    ]                 │   ← 金币/经验 一行
│ 技能                            [＋ 加技能]    │   ← 只有一个按钮，点开是下拉
│ 先攻        怪物首先攻击                  ✕   │   ← 单行：名称 | 介绍 | ✕
│ ┌──────────────────────────────────────────┐ │   ← 多行：整块浅底
│ │ 破甲                                   ✕ │ │
│ │ 战斗前，怪物附加角色防御的…%作为伤害       │ │   ← 介绍整行折行
│ │ 防御百分比 [ 50 ] %                       │ │   ← 参数格：标签 + 数字 + 单位
│ └──────────────────────────────────────────┘ │
│ 纳魔为攻    手册里查不到这个技能的说明      ✕   │
│ ┌──────────────────────────────────────────┐ │   ← 自定义：名称和介绍都能改
│ │ [ 召唤小怪                             ] ✕ │ │
│ │ [ 每两回合召唤一只小怪，最多同时存在 3 只 ] │ │
│ └──────────────────────────────────────────┘ │
│ [删除这只]                    [取消] [保存]     │
└──────────────────────────────────────────────┘
```

- 头像就是换图按钮（用户："点击头像修改图标"），悬停透出「换」。**底部那行
  「图标 / 点头像换图 / 清空」整行删掉**（用户："图标 点头像换图一行都删掉"）。
- 数值：生命/攻击/防御 一行，金币/经验 一行。金币是新加字段（手册上没有），
  存 `monster.gold`，重读手册不会抹掉。
- 技能只有一个按钮 `＋ 加技能`：点开是挂在按钮下方的下拉（第一项「自定义…」，
  下面是手册技能）。原来那行列头（名称/介绍/参数）删了。
- **技能行两种长相**（用户："只有一行的和有多行的要有不同的显示方式，不然看起来
  太丑了"），判断在 `skillRowItem.multi`：
  - 单行：手册查得到、**没有参数**、介绍量过**一行放得下** → 名称 78 宽 | 介绍（一行，
    超出省略）| ✕，整行 26；
  - 多行：**有参数**、介绍一行放不下、或**是自定义技能** → 浅底圆角块：名称一行、
    介绍占满整行折行、参数格往下排。
  - 手册里查不到的技能（例 `纳魔为攻`）在介绍那栏写灰字「手册里查不到这个技能的说明」。
- 技能行三段：
  - **名称**：手册技能**只读**（用户："除了自定义其余技能名称都不能修改"），只有
    「自定义…」那行能改；改成已知技能名会顺手换参数格和介绍。
  - **介绍**：手册技能 `skillinfo.effect_for(name)` 现查（只读，不存存档）；
    **自定义技能是文本框**（`monSkillEffectEdit`，能折行，边打边记），存
    `skill_items[i].effect` + `custom = true`（用户："自定义怎么只能写技能名称
    不能写技能介绍"）；Python 侧 `_parse_skill_payload` 只收 custom 那行的 effect。

## 1.7 伤害计算——另一扇独立窗口

用户："做一个伤害计算的功能：1.根据人物的当前状态计算掉血 2.给一连串东西（怪、宝石、
血），给出打每个怪的掉血及最终掉血 3.考虑技能、多技能兼容 4.思考入口加在哪"。

**入口**是导航条上的 `⚔`：它是工具，不属于地图/怪物/技能任何一栏；导航条收起时也
一直显示；算伤害要边打边看，所以开一扇独立窗口（无边框 + 置顶 + `Qt.Tool`），
能摆在游戏旁边。主界面只有 340 宽，表格铺不开。

**改过七轮**（原话记这儿，别再改回去）：②不能移动/不能读取当前状态/用图代替 →
可拖可钳屏幕内 + 抬头「读取」+ 缩略图参数编辑；③读取要进任务队列；④"一行一个计算"
先被理解成"一行一步"（错了一版）；⑤"一行！！！"→ **一次计算 = 一整行**；
⑥每一条要能单独计算 + 点箭头能插入；⑦"不能拉伸窗口 / 缩略图太大 / 箭头太丑而且
不明显 / 伤害外面要加括号 / 一多就该换行 / 计算按钮在每一条后面 / 血攻防魔防不像
状态那样显示"。

```
┌ 伤害计算   点缩略图改数值 · 点箭头插入 · 点问号接着加      [读取] ✕ ┐
│ ♥ 50000   ⚔ 120   🛡 60   ✚ 30        （图标 + 数，和状态行一个写法）│
│ [＋ 新的计算]                                             [清空]     │
│ 勇 >[血蚊]（−12）>[铁卫]（打不了）>[双头蛇]（−2.99万）>[红宝石]  ✔总掉血 2.99万 ✕│
│                                          >? [计算]      剩血 2.01万   │
│ 勇 >[红宝石]>[双头蛇]（−2.96万）>[铁卫]（打不了）>       ✔总掉血 2.96万 ✕│
│   [血蚊]（−12）>? [计算]                                 剩血 2.04万  │
│ 最少掉血 2.96万（第 2 行）                              [计算]        │
│ 这些技能没算进去：领域：站在范围内每走一步掉血，不在这场战斗里          │
└──────────────────────────────────────────────────────────────────────┘
```

- **一次计算占一整行**：开头是勇者图 + `>`，之后每步 `>` + 一格 14×14 缩略图 +
  括号里的掉血。链是 `Flow`（`battleChain`）：**摆不下就折行**，这一行自己长高
  （用户："我加的怪和资源一多就该换行"），不再是横向滑的 `Flickable`。
- **箭头是画出来的**：两条 1.6px 的短线拼成 `>`（`ChainArrow` 里的
  `battleArrowLeg`），鼠标移上去有药丸底 + 琥珀色。以前是 9 号的 `→` 字，
  用户嫌"又丑又不明显"。
- **窗口能拉大小**（用户："怎么不能拉伸窗口"）：四条边 + 四个角都摆了 `BattleGrip`
  （和「这一层」同一个算法：屏幕坐标算位移、尺寸记进 `battleWinW/H`，因为宽高是
  绑定出来的）。没拉过时窗口高度按内容撑，拉过就按用户的来，加行也不会弹回去。
- **点箭头就插在那儿**（用户："点箭头要能插入"）：链上每个 `>`（`battleRowArrow`）
  都是按钮，选中就插在**那个箭头后面**；链尾箭头（`battleRowArrowEnd`）和问号是
  "接在最后"；菜单标题写「第 N 行：插在第 k 格前面 / 接在最后」。菜单挂在**那一行
  下面**（`placeMenu()` 直接换算那一行的坐标，折行以后不能再拿"行号 × 行高"算）。
- **每行能单独算**（用户："每一条要能单独计算"）：没算时**链尾**跟着这一行自己的
  「计算」（`battlePlanRun` → `battleComputePlan`，用户："计算按钮要在每一条后面"），
  算过就变右边那列的"总掉血 / 剩血"；右下角「计算」是全算。**改哪行只作废哪行**
  （`battleMarkDirty(planIndex)`），改人物数值才全部作废。
- **人物四个数像状态行**（用户："血攻防魔防怎么不像状态一样显示"）：`iconBase` 里的
  hp/atk/def/mdef 图标 + 一个能改的数，点进去才有浅底和琥珀框。
- **链尾常驻问号**：点它弹「选怪或资源」菜单，菜单分**两个标签页**：`怪物` /
  `资源`（用户："应该只有两个标签页分别是怪物和资源（包含 4 色宝石）"）。
  资源那页只列**算得出加成**的东西（`battle.parse_item_effect`），外加四色宝石
  （红/蓝/绿/黄，`iteminfo.GEM_STEMS`）—— 绿宝石加的是敏捷，算式里没有这一项，
  但它就是玩家要拿来算的东西。选中的条目由 `battleFillRow` 接在这一行最后。
  「＋ 新的计算」（`battleAddPlan`）是**再开一行**，不是再开一步。
- **掉血写在怪后面、加括号**：`（−930）` / `（打不了）`（红）/ 打不过也红
  （用户："伤害外面要加括号"）；**资源那格不写字**（用户："只要缩略图"），
  要看 +2 攻就点开它。
- **右边一列对齐的总掉血**：几行摆一起上下成列，最省的打 `✔`，底下一句
  「最少掉血 …（第 N 行）」—— "怎么对比不同排序的掉血"就是这么比的。
- **点「计算」才出结果**：加/删/改之后每格变 `—`，底下写"点「计算」出结果"。
- **点缩略图改数值**：数量、怪的血/攻/防、资源的效果、技能参数（按 `skill_params`
  的 schema 画），改完作废要重算；「删除这步」只删这一格。

**怎么算**（`chaita/game/battle.py`，纯函数、无图无模型）。用户："说了伤害不对，
给我查" —— 把两座塔的引擎源码（`Downloads` 里那两份 `project/functions.js`）逐条
对过，基础三条是这么定的：

| 东西 | 规则（引擎原话） |
|---|---|
| 每回合打怪 | `max(1, 攻击 - 怪防御)`；**攻防正好相等也打得动（1 点）**，只有 `攻击 < 怪防御` 才是「打不动」。`xinxin` 的 `_calculateBaseDamage`：`atk > def → atk-def`；`def-临界 <= atk <= def → 1`；否则 0（临界默认 0） |
| 每回合挨打 | `max(1, 怪攻击 - 防御)`（低于你防御才是 0）× 连击次数。`xinxin2` 的 `plugins.js`：`dmg = m.atk - h.def; if (dmg < -defm(40)) 0; else if (dmg < 1) 1` |
| 回合数 | 逐回合模拟到怪死（吸血会回血、反击会加伤，只能一轮轮试） |
| 掉血 | **`(回合数 - 1) × 每回合挨打`** + 一次性伤害（破甲/固伤/吸血开场/先攻）。**它倒下那回合不再反击**：`xinxin2` 的 `heroAtk` 之后 `if (m.hp <= 0) break;` 才轮到 `monAtk`；`xinxin` 的期望回合数就是 `M - 1`。一刀秒的怪不掉血 |
| 数量 | "打 N 只/吃 N 个"：掉血 ×N、属性 ×N、退化 ×N（`battle.step_count`） |
| 结算 | 血不够 = 「打不过」，掉血最多掉到 0；后面几步标灰不再算 |

一条实测口径（测试钉住了）：你 1200 血/60 攻/30 防打 1200 血/60 攻/20 防的怪 →
每回合打 40、30 回合、**挨 29 下 × 30 = 870**（旧算法错在挨 30 下、还算成"打平防御
就 0 掉血"）。

**技能**：认的是塔引擎的 `code`（`assets/skill_effects.json` 的 special 编号），
名字兜底；数字取**怪物编辑里填的那份**（`assets/skill_params.json` 定参数清单）：

| code | 技能 | 怎么算 |
|---|---|---|
| 1 / 29 | 先攻 | 开打前先挨一回合 |
| 4 / 5 / 6 / 87 | 2连击 / 3连击 / 连击(n) / 一回合六次 | 每回合挨 N 下 |
| 7 | 破甲 | 额外吃 `你的防御 × defValue%` |
| 8 | 反击 | 每回合额外吃 `你的攻击 × atkValue%` |
| 11 | 吸血 | 开打前掉 `你的血 × value%`，怪还回这么多血 |
| 57 / 65 / 66 / 67 | 吸血攻击 / 血秘术… | 它打你的伤害回 50% 给自己 |
| 22 | 固伤 | 开打前固定吃 N 点 |
| 19 | 自爆 | 打赢之后血只剩 1 |
| 3 / 31 / 85 | 坚固 / 变硬 / 硬化+ | 防御顶到你的攻击（85 连攻击也顶）→ 每次只打 1 点 |
| 35 / 10 | 仿攻 / 模仿 | 它的攻防按你的算 |
| 2 / 30 / 60 / 66 | 魔攻 / 无视防御 / 暗魔法 / 血魔法 | 不扣你的防御（60 在防御不够时 ×3） |
| 20 / 36 / 55 | 无敌 / 特殊战斗 / 狙击 | 打不了 / 按 0 伤害 / 它打公主 |
| 21 | 退化 | 战后扣你的攻防，**后面几步按扣完的算** |
| 其余（领域 / 阻击 / 光环 / 支援 / 疲劳 / 中毒 / 必杀 / 秘术 …） | **不算**，列进「没算进去」并说清为什么 |

宝石 / 血瓶：效果那句话解析成属性（`攻击力 +2`、`体力 +150`、多项一起加；`敏捷 +1`
跟伤害无关就忽略），**从这一步之后**的怪都按新属性算。

## 2. 数据：哪些数从哪来

界面不做识别，只做汇总（识别全在读取链路，见 `chaita/game/read.py`）：

| 显示 | 来源 | 汇总规则 |
|---|---|---|
| 地图块 | `controller.mapHistory` | 一层一块；"N 怪 · M 只"按这层记录数 |
| 怪物行 | `monsters × mapHistory` | 同名跨层求和 → `×N`；`done` 的不算"剩" |
| 读怪物手册 | `read.py` → `_deliver_monsters` | **只追加名单里没有的怪**，同名的字段一个不动 |
| 地图上的怪名 | `monster_names.align`（手册名当词汇表） | 对到手册写法；有手册时对不上的不记 |
| 怪物行技能 | `monster.skill_items` | 名字按 ` · ` 拼，没有就退回 `skills` |
| 技能行 | `controller.skillStats` | 只统计地图上加过的怪 |
| 技能参数格 | `assets/skill_params.json` | 技能名 → code → 参数清单 |
| 抬头数值 / 读取时间 | `controller.statusData` / `statusAt` | 空就不显示；时间只在有地图时显示 |
| 对话 / 回话 | `controller.chatLog` / `agent/chat/reply._parse` | 完整历史；回话里的状态 JSON（写坏的也算）一律拿掉 |
| 素材库格子 | `assets/library/manifest.json` | 两座塔的怪物图 + 名字（`build_library.py`） |

- 手册里读过、地图上没有的怪**不列**（不属于这一座塔）；
- 地图上加过、手册没读到的怪**仍然列**（只给 ×N / 剩 N，数值行留空）；
- 顺序 = 用户拖出来的顺序，不按只数排（打完一只只改"剩"，行不会跳）。

## 4. 窗口与尺寸

- 宽 340；**默认高度由内容撑出来**（固定件 = 留白 24 + 导航条 22 + 抬头 24 + 状态 30 +
  间距 + 对话卡，对话卡按实测行高、最少 46、历史多了封顶 180 里滚）。
- **可以自己拉**：拖边缘/拖角就把尺寸记进 `userWidth / userHeight`，之后内容怎么变都按
  用户拉的来；没拉过才跟内容走。上下限：宽 ≥ 260，高 ≥ 240。折叠/展开动画由 Python
  逐帧改尺寸（`controller.animateSize`），动画结束再按"用户尺寸 > 内容高度"算一次。
- 启动时**只恢复位置、不恢复尺寸**（内容撑出来的高度配上次的 847 高就是一大片空白，
  用户："折叠后还是有一大片空白"）；尺寸只在本次会话有效。
- 内容区封顶 `min(560, 72% 屏幕高 - 168)`；窗口被拉矮时内容区跟着变矮并在里面滚。
- 边缘缩放要两个条件同时成立：WM_NCHITTEST 返回 HTLEFT/…（NativeHitTest）；
  窗口样式有 WS_THICKFRAME（`_make_resizable()` 补）。以前的 bug：`desktop.py`
  没 import `ctypes.wintypes`，`_handle` 每次抛 AttributeError 被 try/except 吞掉，
  测试能过、真机拖不动；现在模块自己 import，失败会写 `hit_test.failed` 日志。
- 圆角：外圈 10、卡片 8、按钮/地图块 6、小徽标 5。
- 折叠：有塔名 102 高，什么都没读到 46；`minimumHeight` 只设 40（设大会把折叠高度顶起来）。

## 6. 交互

- **两个「读取」各读各的，能并行**：地图栏 → `readOnly("map")`；怪物栏 →
  `readOnly("monsters")`。**按钮上的字永远是「读取」**（手册分页，翻页再点就是读
  第二页 —— 用户："要通过按读取中来开启第二页太反直觉"），正在读用右上角呼吸小点
  表示（`mapBusyDot` / `monBusyDot`），按钮不 disabled。
- **抓哪扇窗**：`winutil.game_window` = 前台窗口 → 刚采样记住的那扇 → 同进程最大的。
  浏览器两个页面进程都叫 `msedge.exe`，只按"最大"挑就会抓错页面、读回另一座塔的怪
  （用户："哪里来的绿头怪，红头怪"）。只认还看得见的窗口。
- **名字要照抄**：读手册的提示词写明"逐字照抄、别按印象补全（青≠绿）"；读地图时
  手册候选名只用于**统一写法**，图上明显不是就不许硬套。
- **图上读到的名字先对到手册**（`monster_names.py`）：一模一样（去空格标点）就用，
  否则取唯一最像的（≥2 字）；两个一样像就当没对上。有手册时没对上的**不记**
  （任务行写「忽略 N 个对不上手册的名字」）；手册还没读才照原样记。
- **读取记录（任务队列）**：有任务才出现，一行一条 `● 地图/手册 <说明> 12s 取消`；
  跑着显示秒数并给「取消」（`cancelTask`），失败的给「重试」（`retryTask`，沿用当初
  那张截图，不重新抓屏）；右边写「读着 N 条 · 共 M 条」。
- **刷新状态**：抬头 ↻ → `updateStatus()`，只重读人物面板。
- **上次的记录**：`恢复` / `忽略` → `restoreSession()` / `discardSession()`。
- **对话**：回车或 ↑ → `sendChat(text)`；上一句还没回完时不清输入框、不重复发。
- **看大图**：点地图块 → 这层的截图 → 大图层（`PreserveAspectFit`），点任意处或 Esc 关。
- **Esc 顺序**：大图 > 图标/技能挑选 > 怪物编辑 > 加怪/加资源 > 这一层 >
  收起/展开 > 退出；光标在输入框里时 Esc 不退出。
- **关闭**：导航条 ✕ → `controller.quit()`。

| 取消 / 不做 | 为什么 |
|---|---|
| 主界面上的资源分区 | 用户："不需要资源"；资源只在「这一层」里 |

## 8. 已知限制与验收

- **验不出**：外投影（透明窗口抓图会合成黑底）、悬停态（离屏窗口收不到真光标）、
  真机上的拖动手感。
- **字体**：抓图是 1.5 倍 DPR（340 → 510 px），换机器字宽可能差 1–2px，
  所以行宽都用锚点 + 省略号，不写死。
- `long` 那档高度是"屏幕高 72%"封顶出来的，换屏幕会变（check_scenarios 按本机 912 记）。
- 每轮改完必须跑（2026-10-27 实测）：
  - `python -m unittest discover -s tests` → `Ran 662 tests ... OK`
  - `python tools/test_ui_synthetic.py` → 215 项全 PASS
  - `python tools/check_scenarios.py` → 26 场景 0 警告
  - `python tools/smoke_close.py 12` → 退出码 0，`crash.log` 0 字节
  - `python tools/check_close.py a|b|c|d` → 真窗口点击全 PASS
- 截图证据：`logs/design/v12_compact.png`（主界面）、`floor.png` / `floorpick.png`
  （这一层 + 加怪下拉）、`battlecmp.png` / `battleplan.png` / `battleinsert.png` /
  `battleedit.png`（伤害计算）、`monedit.png` / `monparams.png` / `moncustom.png`
  （技能三种长相）、`iconpick.png` / `iconsearch.png`（素材库）、
  `folded.png`（两栏折叠）；全部场景在 `logs/_scenarios/*.png`。
- `logs/_scenarios/*.png` 是**拼出来的**：`preview_overlay.py` 的 `_grab_all()`
  把主窗口和各扇独立窗口按屏幕上的相对位置画到一张图上（单独 `grabWindow()`
  只拍到主窗口）。
- 伤害计算**没算**：必杀（mana 满 ×2 / 必杀剑 ×2.5 / 天地破坏剑 ×4）、护盾/魔防抵扣
  （`damage -= hero_mdef`）、会心/闪避、英雄自己的剑技气息 —— 这些要 `value`/
  临界/装备那套参数，手填不了，界面上列在"没算进去"。血量上限（hpmax）不知道，
  所以"吃血瓶"按当前血量直接加、不封顶。
- 素材库有一条数据是坏的：`恶魔首领`（`xinxin_demon.png`）整张图只有一个颜色
  （白轮廓），看起来是空白的；要修得重新切图。
